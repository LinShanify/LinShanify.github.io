Privacy Policy

Personal tools operated by Lin Shan · linshanify.github.io

Short version: These are single-user tools that run on my own computer and access only my own Google account data. There is no server, no analytics, no third party, and nothing is shared with anyone. If you are not Lin Shan, these tools are not for you and hold no data about you.

1. Who this covers

This policy applies to personal command-line tools and scripts operated by Lin Shan (linshanify@gmail.com), including the Google Cloud OAuth application registered as gws CLI. These tools are not products, are not distributed, and are not offered to other users.

2. What data is accessed

When authorised, the tools may read data from the operator's own Google account through official Google APIs. Scopes currently requested are read-only:

  • gmail.readonly - read mail messages and labels
  • drive.readonly - read files and file metadata
  • calendar.readonly - read calendar events
  • contacts.readonly - read contacts

Access is limited to the account that grants consent. The tools cannot access any other person's Google account.

3. How data is handled

  • Processing is local. Data is read into memory or onto the operator's own machine for personal note-keeping and archiving. It is not uploaded anywhere.
  • No servers. There is no backend, no hosted service, and no database operated by these tools.
  • No third parties. Data is not sold, shared, transferred, or disclosed to any third party, and is not used for advertising or profiling.
  • No analytics or telemetry. The tools do not report usage anywhere.
  • No model training. Data accessed through these tools is not used to train machine learning models.

4. Credential storage

OAuth tokens are stored only on the operator's own machine. Refresh tokens are encrypted at rest with AES-256-GCM, with the encryption key held in the operating system keychain. Tokens are never transmitted other than to Google's own token endpoints.

5. Retention and deletion

Retention is entirely at the operator's discretion, since all copies live on the operator's own machine. Access can be revoked at any time from Google Account permissions, which immediately invalidates all stored tokens.

6. Limited Use disclosure

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

7. Changes

This policy may be updated as the tools change. The revision date below reflects the current version.
